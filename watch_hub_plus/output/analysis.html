『ファイアーエムブレム 万紫千紅』ファイナルプレビュー：複数ルートの並行展開と新たな戦術、そして「鳥」になるお茶会

ナンバリング第18作目となる『ファイアーエムブレム』の発売が目前に迫ってきた。序盤の数時間をプレイして見えてきた、本作の手応えをお届けする。 プレビューの主なポイント： 『万紫千紅』は各主人公の個別の物語を前倒しで描く構成を採用しており、この試みは大いに評価できる。 新要素「ブレイズアーツ」は、リスクとリターンが背中合わせの刺激的な戦闘システムをもたらしている。 ストーリーのルート間を自由に行き来できるようになった一方で、セーブデータ周りの仕様は、全要素を網羅したいプレイヤーにとって少し不満が残るかもしれない。 『ファイアーエムブレム 風花雪月』で描かれた世界に、7年の時を経て『ファイアーエムブレム』が帰ってきた。『ファイアーエムブレム 万紫千紅』の構造には『風花雪月』との共通点が数多く見られるが、開発を手掛けたインテリジェントシステムズは、『風花雪月』を象徴する要素を実に見事な形で拡張している。今回の試遊プレイでは各主人公の物語を数章進めた程度にとどまるが、すでに非常に気に入った新要素がいくつも見つかった……そして、ひとつだけあまり感心しなかった要素も。 1) 英雄の道を歩む 『万紫千紅』のプロローグミッションをいくつかこなした時点で、言葉を発しない（だが若干のキャラメイクが可能な）プレイヤーの分身・イシュマールが、アンデッドに侵略された絶望的な状況下で防衛の要として孤立無援の窮地に立たされていることを悟った。自力で戦争に勝つ見込みがないエシュメルは、早々に前線から身を引く。プレイヤーは時を遡り、「大剣闘祭」と呼ばれるコロシアムでの戦いに挑む4人の英雄の誰か1人を操作することになるのだ。 過去へ送られる名目の理由は、英雄の1人を「支援」して生存させ、現代での戦いに協力してもらうためだ。しかし興味深いのは、遠い未来の脅威よりも、英雄個人の物語がストーリーの中心としてスポットライトを浴びている点である。これにより、どの主人公を選んでも同じような展開をなぞらされることがなく、それぞれのキャラクターに密接に関わる謎を解き明かしていく独自のドラマが展開される。 たとえば、幼い少年カイを選択すると、彼の父親が間もなく投獄されるダグザ帝国の首都へと向かう展開になり、大剣闘祭の出場資格を得るための選考イベントに挑戦することになる。一方で、復讐に燃える音楽家であり踊り子のレダでプレイすると、父親を殺害した犯人たちを追跡して討ち取る血塗られた復讐劇の渦中へと放り込まれる。大剣闘祭へと至る道のりはカイの辿った道とは全く異なっており、レダは女神の助けによって、大会開幕直前に到着したにもかかわらず滑り込みで出場を果たせる。 これまで見てきた限り、『万紫千紅』は『風花雪月』とは対極のアプローチを取っているようだ。序盤で各主人公の個性的でパーソナルなドラマを前面に押し出し、その後に物語が集約して、プレイヤーが育成してきた各ルートの仲間たちと合流し、大陸を蹂躙するアンデッド軍勢に立ち向かう構造になっていると推測される。これは非常にスマートな手法であり、序盤で丹念に育んだキャラクターたちと後半でどのように共闘できるのか、期待が高まる。 2) 呪われし絆の力 各ルートの独自性を高めているもうひとつの優れた要素が、主人公ごとに用意された固有のアビリティ群、とりわけ新技「ブレイズアーツ」の存在だ。主人公たちはそれぞれ呪われているとされる神器を手にすることになり、カイなら爆発する火の玉を放ち、ディートリヒなら障壁をすり抜けてテレポートし、レダなら歌で味方を強化するといった、戦場での新たな戦術を展開できる。 この強力な技には、考慮すべき興味深い副作用が存在する。使用すると自身のHPを一定量消費するが、同時に専用のゲージが溜まっていく（これは『ファイアーエムブレム エンゲージ』から着想を得た数少ない要素のひとつのようだ）。1回の戦闘の中でブレイズアーツを何度も使用すると、そのヒーローのステータスが大幅に強化される。しかし、頼りすぎてゲージが限界まで溜まると「バースト」を引き起こし、戦闘終了まで最大HPが減少してしまう。リスクとリターンを見極め、ヒーローを危険に晒すことなくパワーを引き出す「限界点」を探る試行錯誤が実に楽しい。 戦闘以外でも、各主人公の生い立ちや個性が他のルートにはない新たな可能性を生み出している。カイの生まれ持っての優しさは助けを求める人々を察知しやすく、未熟さを補うほど多くの「名声」を獲得できる。一方、レダは世界マップ上の街で演奏を披露することで、ユニークな報酬やブレイズアーツ用の新たな楽曲を手に入れることができる。誰を操作しているかによって世界を探索するルート自体が変わってくるような、こうした細やかな作り込みが素晴らしい。 3) 果てしなく続く道 世界探索と言えば、『万紫千紅』にはワールドマップの移動にもユニークな工夫が凝らされている。ダグザ帝国に馴染み、その首都に到着すると、大剣闘祭が始まるまでの自由時間を使って大陸を散策できるようになる。街の中にも遊べる要素は豊富にあるが（『風花雪月』のガルグ＝マク大修道院のように）、街の中での行動で時間が経過することはめったにない。本当の意味で時間を進めるには、外の世界へと踏み出す必要があるのだ。 上海から世界へ――COREBLAZER Game Festはいかに中国のインディーゲームと世界のパブリッシャーをつなぐのか【PR】

ただの展示会にしない、COREBLAZER Game Festが目指すところ 一見すると、COREBLAZER Game Festはほかのインディーゲーム展示イベントと変わらないように映る。しかし、プレイアブルデモや展示ブースの裏には、『アークナイツ』及び『アークナイツ：エンドフィールド』の開発元であるHypergryphによる長期的な戦略が存在する。それは、優秀なインディーゲーム開発者たちを、世界各国のパブリッシャー、投資家、そして業界パートナーと結びつけるというものだ。 COREBLAZER Game Fest 2026は、優秀なインディーゲーム開発者を世界各国のゲーム業界と結びつけることを目的としたイベントとして、上海で開催された。 COREBLAZER Game Fest（CGF）は、2026年7月25日・26日に上海で開催され、4年連続での開催となった。今年のCGFは、その国際的な野心がどれほど大きく成長したかを示すものとなった。数十の中国のインディースタジオや学生開発者と並び、展示フロアにはPlaystack、Devolver Digital、room6、Fireshine Games、集英社ゲームズ、Triple-i initiativeを含む海外の著名なパートナーが出展した。各社は中国の観客に向けて自社のゲームを展示すると同時に、海外でのパブリッシングの機会を探す現地の開発者と面談を行った。 この組み合わせこそが、COREBLAZERが実現しようとしているものだ。 Hypergryphが、開発初期のチームから成長段階にあるゲームスタジオまで、幅広い開発者への投資とインキュベーションを行うグローバル投資ブランドとして立ち上げたCOREBLAZERだが、その活動は有望なゲームに単に投資するだけにとどまらない。Hypergryphは大学時代からの仲間たちを中心に設立され、『アークナイツ』で自らの成功を築き上げた。現在、同社は苦労して得たその経験を生かし、次の世代へと還元しようとしている。COREBLAZERは、初期段階の資金提供、インキュベーション施設、ビジネスおよび法務サポート、マーケティング支援、そしてパブリッシャー、投資家、専門パートナーからなる広範な国際ネットワークへのアクセスを提供している。重要なのは、これらの支援を行いながらも、スタジオがプロジェクトにおける完全なクリエイティブ上の独立性を維持できるようにしている点だ。 これまでCOREBLAZERは約30の開発チームに投資を行い、そのうちおよそ半数について初の商業作品のリリースを支援してきた。また、2作目のプロジェクトに着手する多くのチームへの支援も継続している。さらに上海にあるインキュベーション拠点では、10社以上のスタートアップスタジオが持続可能な事業を確立するための支援も行ってきた。 しかし、COREBLAZERの拡大に伴い、その視野もまた広がってきた。 「私たちは、異なる地域やゲーム業界のさまざまな分野の間に架け橋を築きたいとつねに考えてきました」と、COREBLAZERの代表であるクレア・ヤン氏は説明する。「長い間、多くの中国の開発者はほぼ国内市場だけに注力してきました。一方で、海外のパブリッシャーは言語の壁や文化の違いから、中国での活動を難しいと感じることが多くありました。これに対して双方を結びつけることが私たちの責任だと感じていたのです」 その哲学は、今年のイベント全体を通じて見て取れた。COREBLAZERは海外のパブリッシャーを単にゲームを展示してもらうために招待するのではなく、彼らに（無料で）ブースを提供し、本来なら決して生まれなかったであろう中国のインディー開発者たちとの対話の機会を生み出しているのだ。 「中国の開発者が海外のパブリッシャーと直接出会えるようにするため、私たちは海外のパブリッシャーに展示ブースを無料で提供しています」とクレア氏は語る。「同時に、そうしたパブリッシャーも中国の開発コミュニティをよりよく理解できるようになります。時間をかけて、双方が信頼を築いていくのです」 …
